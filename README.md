# Machine Learning Projects 🚀

Welcome to my Machine Learning Projects repository!

This repository contains my hands-on projects built while learning and exploring Machine Learning, Data Science, and Python. These projects demonstrate my understanding of data preprocessing, exploratory data analysis, model building, and evaluation.

## 🛠️ Technologies & Tools

- **Programming Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
- **Platform:** Google Colab
- **Version Control:** Git & GitHub

## 📂 Projects

### 1. Healthcare Risk Classifier 🏥

**Type:** Classification

A Machine Learning project focused on analyzing healthcare-related data and identifying potential health risks based on medical attributes.

**Key Concepts:**
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature selection and model training
- Classification algorithms
- Model evaluation

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

### 2. House Price Prediction 🏠

**Type:** Regression

A Machine Learning project that predicts house prices based on relevant property features using regression techniques.

**Key Concepts:**
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Feature engineering
- Regression model development
- Model performance evaluation

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Google Colab

### 3. Titanic Survival Prediction 🚢

**Type:** Classification

A Machine Learning project that predicts whether a passenger survived the Titanic disaster based on passenger-related information.

**Key Concepts:**
- Handling missing values
- Data preprocessing and encoding
- Exploratory Data Analysis
- Classification model training
- Model evaluation using performance metrics

**Technologies:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Google Colab

## 🎯 Learning Objectives

- Develop practical Machine Learning skills.
- Understand data preprocessing and EDA.
- Apply classification and regression algorithms.
- Evaluate model performance using appropriate metrics.
- Gain hands-on experience with real-world datasets.
